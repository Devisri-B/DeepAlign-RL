DeepAlign-RL Architecture & Design Specifications

System architecture, objective formulations, and key engineering trade-offs.

Mathematical Foundation: GRPO vs PPO

1. Elimination of the Value Network

Traditional PPO requires training a separate Value Network $V_\phi(s)$ with identical parameter scale to the policy model, requiring 50%–100% additional GPU memory and complex GAE advantage bootstrapping.

GRPO replaces the critic by drawing a group of $G$ rollouts $\{o_1, \dots, o_G\} \sim \pi_{\text{old}}(q)$ and standardizing advantages directly over the group:

Âi = (ri - mean({r})) / (std({r}) + ε)

2. Token-level Clipped Objective

LCLIP(θ) = (1/G) ∑ (1/|oi|) ∑ min(rt(θ) Âi, clip(rt(θ), 1-ε, 1+ε) Âi)

3. Exact Response Masking

Gradients strictly propagate through response reasoning tokens $[p_{\text{len}} : \text{seq}_{\text{len}}]$, maintaining prompt invariance.

Engineering Trade-offs & Design Choices

Memory Footprint

Eliminating the auxiliary critic network reduces peak training VRAM by ~50%, allowing higher rollout throughput and larger group sizes $G$ on memory-constrained hardware.

Reward Integrity

Replacing learned reward models with deterministic SymPy symbolic algebra eliminates verifier gaming and length exploitation on mathematical reasoning tasks.

Gradient Masking

Masks prompt tokens from policy gradients, isolating updates strictly to generated reasoning steps and answer segments.

Algorithmic Flexibility

Provides unified interfaces for comparing online reinforcement learning (GRPO) with offline preference optimization (DPO) under identical tokenizers and architectures.
